تحديث القافية: أدوات القراءة وإصلاح اختيار الشاعر

الملفات داخل هذا ZIP تُنسخ إلى جذر مشروع القافية وتستبدل الملفات المطابقة فقط:
- admin.html و admin-extras.js: إصلاح قائمة الشعراء مع البحث واختيار الشاعر المسجل.
- poem.html و article.html و poet.html: تفعيل أدوات القراءة والمشاركة.
- qafiyah-poem-tools.js: أدوات التحكم والعرض والصور والمشاركة.
- qafiyah-new.css: تنسيق الأدوات الصغيرة بشكل منسجم مع التصميم السابق.

بعد رفع الملفات إلى GitHub وتنفيذ النشر المرتبط بالمستودع، افتح الموقع ثم أعد تحميل الصفحات (Ctrl+Shift+R).
لا حاجة إلى تنفيذ SQL إضافي. أبقِ ملفات الموقع الأخرى والخطوط كما هي.

ملاحظات:
- حجم الخط يزيد/ينقص 2 بكسل، والتباعد يزيد/ينقص 2 بكسل، الإعدادات مؤقتة لكل صفحة وليست لخط الموقع العام.
- أنماط الشعر: العرض الأصلي للبيت في سطر واحد؛ وعرض الديوان شطر أيمن ثم شطر أيسر تحته. تحديد الشطرين يعتمد على تنسيق النص المحفوظ؛ الأسطر غير المنفصلة بوضوح قد تُعرض كسطر كامل.
- حفظ الملفات: يستخدم نافذة حفظ ملفات عند دعم المتصفح لها؛ وإلا يقوم بتنزيل PNG. التطبيقات تظهر من قائمة المشاركة الأصلية في الجهاز عند دعم Web Share API، وليس بالإمكان إجبار كل الأجهزة على عرض تطبيق بعينه.
- المحتوى الطويل قد ينتج عنه صور متعددة من نافذة معاينة الصورة. خيار «حفظ في الملفات» يحفظ أول صفحة؛ ولحفظ بقية الصور افتح «حفظ كصورة» وتنقّل بين الصفحات.
- لا يوجد تعديل لقاعدة البيانات أو التصميم العام. اختبر على بيئة تجريبية قبل النشر.
