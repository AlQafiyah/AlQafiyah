تحديث عداد المستخدمين وجدول بياناتهم
=====================================

1) فك ضغط ملف Qafiyah-users-count-fix.zip.
2) انسخ admin.html وusers-count-update.sql.
3) الصقهما داخل مجلد موقعك الحالي الذي يحتوي على index.html.
4) اختر استبدال admin.html عند ظهور رسالة الاستبدال.

5) افتح Supabase ثم مشروع قافية.
6) اضغط SQL Editor ثم New query.
7) افتح users-count-update.sql وانسخ محتواه كاملًا.
8) الصقه في SQL Editor ثم اضغط Run.
9) ظهور Success. No rows returned يعني نجاح التحديث.

10) افتح Visual Studio Code ثم File ثم Open Folder.
11) اختر مجلد الموقع نفسه واضغط Select Folder.
12) افتح Terminal ثم New Terminal.
13) نفّذ الأوامر التالية بالترتيب:

git add admin.html users-count-update.sql

git commit -m "إصلاح عداد المستخدمين"

git push origin main

14) انتظر تحديث Cloudflare ثم افتح لوحة الإدارة.
15) العداد وجدول المستخدمين سيقرآن جميع الحسابات الموجودة في Authentication > Users.
16) سيظهر البريد الإلكتروني، مع دمج الاسم والهاتف والميلاد والجنس من profiles إن وجدت.
17) أثناء فتح قسم المستخدمين سيعاد تحديث العدد والبيانات تلقائيًا كل 30 ثانية، وكذلك عند الرجوع إلى الصفحة.
