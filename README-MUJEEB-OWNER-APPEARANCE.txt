القافية — تحديث مظهر مُجيب (مرحلة المظهر والصلاحيات)

المحتويات: ملفات واجهة مُجيب فقط + admin.html + admin-extras.js + صورتا الخلفية الأصليتان + ملف SQL جديد.
هذا التحديث لا يغيّر ملفات مِضمار، القصائد، المقالات، أو ملفات الموقع الأخرى.

1. احتفظ بنسخة احتياطية من الموقع وSupabase.
2. فك الضغط وانسخ محتويات مجلد AlQafiyah إلى مجلد موقعك المنشور، واستبدل الملفات المطابقة فقط.
3. Supabase Dashboard > SQL Editor > New query: افتح ملف QAFIYAH-MUJEEB-OWNER-APPEARANCE.sql، وانسخه وشغّله مرة واحدة.
   ملاحظة: يجب أن تكون قاعدة بيانات مُجيب الأصلية موجودة (بعد ملف مُجيب ومِضمار السابق).
4. ارفع ملفات المشروع إلى GitHub ونفّذ نشر Cloudflare المعتاد إذا لم يكن تلقائياً.
5. افتح /mujeeb.html وتحقق من تبديل الليل/النهار. افحص على الجوال والكمبيوتر.
6. ادخل كمالك: لوحة الإدارة > مُجيب، ثم عدّل الاسم والوصف والصورة والخلفيتين واحفظ.
7. اختبر بحساب مدير: لا تظهر إدارة مُجيب، وتمنع قاعدة البيانات تحديث إعداداته.

- صورة الشخص الافتراضية هي نفس رمز الصورة الافتراضية في صفحة ملف المستخدم الحالية؛ بلا أحرف ولا إيموجي.
- الخلفيتان هما الصور التي زودتنا بها؛ وقد أُدرجت صور JPG الأصلية دون إعادة ترميز أو تعديل النقوش.
- الوضع الليلي هو الافتراضي لأول زيارة، والنهاري بزر الشمس، مع تبديل الرمز إلى الهلال والعكس.
- الخط يأخذ اختيار «خط الموقع» المحفوظ لدى الزائر؛ لا يغيّر اختيار الخط العام.
- الملفات الافتراضية يُستعاد عرضها عند إزالة الصورة أو الخلفية المخصصة من إدارة مُجيب.
- الخلفية بحجم cover تحافظ على نسبة أبعاد الصورة وتقتطع أطرافاً عند اختلاف نسبة الشاشة؛ لا يتم مدّ النقوش أو تشويهها.
- رفع صور الإدارة إلى Supabase Storage bucket باسم mujeeb-assets؛ إنشاء bucket وسياسات الصلاحية يتم عبر SQL.
- الصور العامة تحفظ باسم فريد. رفع أو حذف الصور وإعدادات مُجيب مقيد بالمالك، لا المدير.
- لا تعيد تشغيل SQL الأصلي القديم الذي يتيح تحرير إعدادات مُجيب للمدير بعد SQL المرفق.
- إذا بدا الموقع قديماً: أعد التحميل بدون ذاكرة التخزين أو امسح الكاش من متصفحك بعد نجاح نشر Cloudflare.
- لم تُنفّذ اختبارات اتصال حقيقية على مشروع Supabase الشخصي؛ تأكد بنفسك من نجاح SQL ومن صلاحيات المالك بعد النشر.

تنبيه: التحقق من الصلاحيات يحتاج تجربة على Supabase الحقيقي بعد تطبيق SQL. لا تُعد تشغيل SQL القديم الواسع بعد هذا التحديث.
