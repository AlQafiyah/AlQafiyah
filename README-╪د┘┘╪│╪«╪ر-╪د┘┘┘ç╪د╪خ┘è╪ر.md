# قافية — النسخة النهائية

هذه الحزمة مبنية على ملف `Qafiyah.zip` الأخير الذي تم تسليمه، مع الحفاظ على لوحة الإدارة وSupabase والهوية الأساسية.

## ما تم إنجازه
- توحيد عرض القصائد مع أسلوب بطاقات المقالات والشعراء.
- الصور تحافظ على أبعادها الأصلية (أفقي/عمودي/مربع) بدون إجبارها على مربع وبدون خلفية أو إطار أبيض مفروض، مع حواف مقوسة للصورة نفسها.
- عداد أحمر صغير بجوار جرس الإشعارات يعرض عدد الإشعارات غير المقروءة، ويختفي عند فتح الجرس. حالة القراءة مستقلة لكل متصفح.
- صفحة إعدادات حقيقية: خطوط + لغة + رؤية فاتحة/داكنة/صباحية/ليلية.
- الخط الأساسي محفوظ باسم السعودي العريض وموسوم بأنه (الأساسي)، مع خطوط Expo المرفوعة وخيارات خطوط عربية إضافية. اسم كل خط داخل الإعدادات يعرض بنفس الخط.
- زر اللغة يعرض الرسالة: «هل صدّقت؟ إنها موسوعة أدب وشعر عربي، وتريد لغة أخرى؟» مع زر ×.
- مفضلة تعمل للمقالات والقصائد والشعراء مع قلب فارغ/ممتلئ وصفحة منظمة: الكل / المقالات / القصائد / الشعراء.

## الاستبدال
انسخ محتويات هذا المجلد فوق مشروعك الحالي مع الاستبدال. لا تحذف ملفاتك الأخرى إن كنت أضفت ملفات خارج هذه الحزمة.

## Supabase — خطوة واحدة فقط
إذا سبق أن شغّلت `admin-security.sql` في النسخة القديمة، افتح Supabase > SQL Editor وشغّل:

`qafiyah-final-upgrade.sql`

هذا يضيف صلاحية قراءة الإشعارات للواجهة العامة فقط. لا يعطي الزوار صلاحية إضافة أو تعديل أو حذف الإشعارات.

أما إذا ستجهز قاعدة البيانات من الصفر بهذه النسخة، فيكفي تشغيل `admin-security.sql` الأحدث الموجود في الحزمة حسب خطوات مشروعك السابقة، لأنه يحتوي التعديل نفسه.

## تحديث الرؤى الخمس
تم تحديث نظام الرؤية ليعمل على كامل واجهة الموقع بتناسق موحد، مع خمسة خيارات:
- الطبيعية: التصميم الأصلي لقافية كما كان قبل إضافة نظام الرؤى.
- الفاتحة: خلفيات فاتحة هادئة ونص داكن واضح.
- الداكنة: خلفيات داكنة دافئة ونص فاتح عالي الوضوح.
- الصباحية: درجات كريمية دافئة ومريحة.
- الليلية: درجات أزرق ليلي هادئ مع نص فاتح.

تشمل الرؤية: رأس الموقع، القائمة، الإشعارات، البطاقات، صفحات المقالات والقصائد والشعراء، المفضلة، الإعدادات، النوافذ، الأزرار، الحقول، البحث والفوتر.
