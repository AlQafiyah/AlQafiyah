القافية — إصلاحات لوحة إدارة سِجال
================================
هذه الحزمة مبنية على AlQafiyah-Sijal-Last-Fixes-FULL.zip (النسخة السابقة).

التغييرات فقط:
- إدارة الأسئلة: اختيار عرض 10/50/100 سؤال، وصفحات السابق/التالي مع البحث والتصفية. تحميل جميع الأسئلة على دفعات بسبب حدود Supabase الافتراضية.
- الاستيراد: تغيير عنوان القسم إلى «استيراد الأسئلة».
- اللاعبون: زر «التفاصيل» يفتح ويغلق المعلومات عند الضغط مجدداً؛ إضافة «تعديل» النقاط/الجولات/الإجابات/الصحيحة، وخيارات «تصفير» لأي مؤشر أو الجميع.
- إدارة الألعاب: البحث نفسه بعنوان «ابحث في الألعاب»، وأزرار «إخفاء/نشر» و«حذف» فقط؛ تسجيل تغييرات الإظهار عند الضغط على زر «حفظ» أسفل الجدول.
- استبدال رمز السهم التعبيري بأيقونة SVG في زر «عرض سِجال».

الملفات المعدلة: admin.html، admin-extras.js فقط.
ملف قاعدة البيانات الجديد: QAFIYAH-SIJAL-PLAYER-ADJUSTMENTS.sql
لم تتغير أي ملفات لواجهة الألعاب أو مُجيب أو القصائد.

طريقة التثبيت:
1. احتفظ بنسخة احتياطية من قاعدة البيانات والموقع.
2. افتح مشروع القافية في Supabase > SQL Editor. الصق SQL الجديد وشغّله مرة واحدة.
3. بعد نجاح SQL، استبدل admin.html وadmin-extras.js فقط في مشروعك (حافظ على بقية الملفات الأصلية).
4. انشر المشروع من GitHub إذا كانت الاستضافة متصلة به:
   git add .
   git commit -m "Polish Sijal admin panel"
   git push origin main
5. انتظر اكتمال نشر Cloudflare وحدّث الصفحة ثم جرّب بحساب المالك أو المدير.

ملاحظات مهمة:
- لا تعِد تشغيل ملفات SQL القديمة ولا تحذف سجلات الإجابات. الدالة الجديدة تحفظ فروق التعديل في جدول خاص دون حذف تاريخ اللاعب.
- صلاحيات تعديل بيانات اللاعب تُفحص في دالة Supabase نفسها (المالك والمدير فقط)، فضلاً عن إخفاء اللوحة عن بقية الأدوار.
- إجراء «حذف لعبة» دائم؛ انتبه إلى رسالة التأكيد لأن أسئلتها ونتائجها المرتبطة قد تُحذف حسب قيود قاعدة البيانات.
- اختُبرت وظائف الواجهة على متصفح محلي ببيانات تجريبية فوق 1100 سؤال. لم تُنفَّذ الترقية على Supabase الفعلي ولا اختبار صلاحيات قاعدة بيانات الإنتاج.
