القافية — سِجال | التحديث الموحّد

هذه النسخة مبنية على أحدث ملف أرسلته: AlQafiyah(2).zip.

تثبيت آمن:
1. احتفظ بالنسخة الاحتياطية لملفات الموقع وقاعدة البيانات.
2. فك الضغط وانسخ محتويات مجلد AlQafiyah إلى مجلد مشروعك الحالي، واستبدل الملفات المتشابهة فقط. لا تحذف ملفات المشروع الأصلية ولا مجلد .git.
3. في Supabase > SQL Editor افتح QAFIYAH-SIJAL-UPGRADE.sql الموجود داخل الملف، وانسخ محتواه وشغله مرة واحدة بعد التحقق من أنك نفذت تحديث «مجيب ومضمار» الأقدم. لا تعِد تنفيذ التحديثات القديمة.
4. ادفع التغييرات إلى GitHub بالأوامر: git add . ثم git commit -m "Launch Sijal" ثم git push origin main. إذا كان Cloudflare مربوطاً بالمستودع، انتظر نجاح Deployment.
5. افتح sijal.html واختبر اللعب الفردي والفرق. افتح لوحة الإدارة وتحقق من الصلاحيات بالمالك والمدير وبحساب كاتب/مشرف.

الإضافات:
- استبدال الاسم العام «مضمار» بـ«سِجال» بما فيها القوائم ولوحة الإدارة، مع إعادة توجيه رابط midmar.html القديم.
- 6 أنواع ألعاب شعرية وأدبية، تشغيل لعبة واحدة أو عدة ألعاب، واللعب الفردي أو الفرق (2-4).
- الفرق بأسماء فقط أو مع أسماء اللاعبين، ونقاط الجولة منفصلة عن التصنيف الفردي.
- تصنيف أفراد ومتابعة النشاط وعدد الجولات للأسئلة المسجلة بحسابات المستخدمين.
- إدارة الألعاب والأسئلة والمرفقات والتصنيف، إخفاء الألعاب والقسم كاملاً، استيراد JSON وCSV.
- رأس وتذييل وقوائم مثل صفحات القافية، توافق الأجهزة والألوان والمظاهر الخمسة.

تنبيهات مهمة:
- استيراد JSON/CSV للأسئلة المهيكلة، وليس توليد أسئلة تلقائياً من PDF والكتب.
- تغييرات Supabase الحية والسياسات لا يمكن اختبارها على بيانات موقعك من هنا؛ اختبرها أولاً على نسخة تجريبية.
- رفع المرفقات يتطلب تشغيل ملف SQL الذي ينشئ bucket التخزين وصلاحياته.
- الملف المضغوط لا يحتوي مجلد .git كي لا يستبدل إعدادات المستودع لديك.
