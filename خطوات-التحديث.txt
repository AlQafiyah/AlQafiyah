هذا التحديث لا يحتاج تشغيل أي كود SQL.

1) فك ضغط ملف Qafiyah-final-display-fix.zip.
2) ستجد ملفين: admin.html و content.js.
3) افتح مجلد مشروع قافية الحالي الذي يوجد داخله index.html.
4) انسخ الملفين admin.html و content.js إلى مجلد المشروع نفسه.
5) عند ظهور سؤال الاستبدال اختر: استبدال الملفات في الوجهة.
6) افتح مجلد المشروع نفسه في Visual Studio Code.
7) افتح Terminal ثم نفّذ الأوامر التالية، كل أمر لوحده:

git add admin.html content.js

git commit -m "تحسين عرض القصائد والشعراء والمقالات"

git push origin main

8) انتظر اكتمال نشر Cloudflare، ثم افتح الموقع في نافذة خاصة أو حدّث الصفحة تحديثًا قويًا.

مهم: لا تنسخ مجلدًا داخل مجلد المشروع. انسخ الملفين الموجودين داخل المجلد المضغوط مباشرة إلى جانب index.html.
