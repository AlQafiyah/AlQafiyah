القافية V21 — تعليمات النشر

1) خذ نسخة احتياطية من ملفات الموقع وقاعدة بيانات Supabase.
2) في Supabase SQL Editor شغّل V21_SQL_FINAL.sql كاملًا. لا تشغّل SQL V20 منفصلًا؛ عمود is_visible مضمن هنا.
3) انسخ جميع ملفات هذا المجلد إلى مستودع القافية، مع الاحتفاظ بإعدادات Git الخاصة بالمستودع.
4) افتح PowerShell داخل مجلد المستودع وشغّل:
   git status
   git add .
   git commit -m "V21 - Admin dashboard roles maintenance media ads"
   git push origin main
5) بعد النشر تحقق من لوحة الإدارة وروابط التواصل والإعلانات والصيانة باستخدام حساب المالك وحساب زائر.

ملاحظات مهمة:
- هذا الإصدار لم يُختبر على قاعدة بيانات Supabase الفعلية؛ اختُبرت صياغة JavaScript ووجود العناصر في HTML فقط.
- وضع الصيانة حاجز واجهة أمام الزائر، وليس حظرًا للخادم أو حماية لبيانات Supabase؛ يمكن للمتقدم تقنيًا تجاوزه. يلزم ضبط Cloudflare Worker أو Access لقفل الخادم فعليًا.
- أرقام الإعلان إحصاءات تقريبية تعتمد على معرّف زائر محفوظ في المتصفح؛ لا تُعد قياسًا موثقًا للمستخدمين الحقيقيين.
- روابط الإعلان ووسائطه تستخدم روابط HTTPS مباشرة؛ لا توجد واجهة رفع ملفات للإعلان في هذا الإصدار.
- قبل تشغيل وضع الصيانة، جرّب استثناء حساب المالك والمدير على نسخة تجريبية.
