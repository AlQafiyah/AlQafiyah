خطوات تشغيل وحدة الإدارة في القافية
===================================

أولًا: إعداد Supabase مرة واحدة
--------------------------------
1. افتح مشروع القافية في Supabase.
2. من القائمة اليسرى افتح SQL Editor.
3. اضغط New query.
4. افتح ملف admin-security.sql الموجود داخل هذا المجلد.
5. انسخ محتواه كاملًا والصقه في صفحة SQL Editor.
6. اضغط Run.
7. في النتيجة يجب أن يظهر:
   role = super_admin
   is_active = true

ثانيًا: تشغيل الموقع واختباره
----------------------------
1. شغّل الموقع بالطريقة المعتادة.
2. سجّل الدخول بحساب وليد المرتبط بالمعرّف الموجود في ملف SQL.
3. افتح قائمة الخطوط الثلاثة.
4. سيظهر خيار «وحدة الإدارة» لهذا الحساب فقط.
5. سجّل الخروج: يجب أن يختفي الخيار.
6. سجّل الدخول بحساب مستخدم عادي: يجب ألا يظهر الخيار.
7. إذا كتب المستخدم العادي admin.html يدويًا، ستظهر له صفحة رفض الوصول ولن تُفتح لوحة الإدارة.

ثالثًا: إضافة مدير جديد لاحقًا
------------------------------
1. يجب أن ينشئ الشخص حسابًا في الموقع أولًا.
2. افتح Supabase > Authentication > Users.
3. انسخ User UID الخاص بحسابه.
4. ادخل إلى وحدة الإدارة بحساب super_admin.
5. افتح «المديرون والصلاحيات».
6. اضغط إضافة مدير.
7. الصق User UID واختر admin أو super_admin ثم احفظ.

مهم
----
- admin يستطيع إدارة المحتوى.
- super_admin يستطيع إدارة المحتوى والمديرين والصلاحيات.
- لا تمنح super_admin إلا لشخص موثوق.
- لا تضع service_role key داخل ملفات الموقع مطلقًا.
