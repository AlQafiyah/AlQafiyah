تحديث الصوتيات في موقع قافية
============================

أولًا: تحديث قاعدة البيانات (مرة واحدة فقط)
1) افتح Supabase.
2) افتح مشروع موقع قافية.
3) من القائمة اليسرى اضغط SQL Editor.
4) اضغط New query.
5) افتح ملف audio-update.sql الموجود مع التحديث وانسخ محتواه كاملًا.
6) الصق المحتوى في SQL Editor.
7) اضغط Run.
8) ظهور Success. No rows returned يعني أن الخطوة نجحت.

ثانيًا: تحديث ملفات الموقع
1) أغلق Visual Studio Code.
2) فك ضغط ملف Qafiyah-audio-update-files.zip.
3) ستجد الملفات: admin.html وcontent.js وaudio-update.sql وملف الخطوات.
4) انسخ الملفات الأربعة.
5) افتح مجلد مشروعك الحالي الذي يحتوي على index.html.
6) الصق الملفات داخله.
7) اختر Replace the files in the destination عند ظهور رسالة استبدال admin.html وcontent.js.
8) افتح Visual Studio Code.
9) اضغط File ثم Open Folder.
10) اختر مجلد مشروعك الحالي الذي يحتوي على index.html ثم اضغط Select Folder.

ثالثًا: رفع التحديث إلى GitHub وCloudflare
1) من Visual Studio Code اضغط Terminal ثم New Terminal.
2) اكتب الأمر التالي واضغط Enter:
   git add admin.html content.js audio-update.sql
3) اكتب الأمر التالي واضغط Enter:
   git commit -m "إضافة الصوتيات للقصائد"
4) اكتب الأمر التالي واضغط Enter:
   git push origin main
5) انتظر حتى ينتهي الأمر من دون خطأ.
6) Cloudflare سيبدأ نشر النسخة الجديدة تلقائيًا من GitHub.

رابعًا: إضافة صوت إلى قصيدة
1) افتح موقعك وسجل الدخول بحساب أدمن أو سوبر أدمن.
2) افتح القائمة ذات الثلاثة خطوط.
3) اضغط وحدة الإدارة.
4) افتح قسم القصائد.
5) اضغط إضافة قصيدة، أو تعديل بجانب قصيدة موجودة.
6) انزل إلى: التسجيل الصوتي للقصيدة (اختياري).
7) اضغط اختيار ملف واختر الصوت من جهازك.
8) الصيغ المدعومة: MP3 وM4A وAAC وWAV وOGG، والحد 50MB.
9) اضغط حفظ وانتظر حتى ينتهي الرفع.
10) افتح القصيدة في الموقع العام؛ سيظهر زر استمع إلى القصيدة.
11) اضغط الزر للتشغيل، واضغطه مرة أخرى للإيقاف المؤقت.

ملاحظة:
- الصوت اختياري؛ القصائد التي لا تحتوي على صوت لن يظهر فيها زر التشغيل.
- لحذف الصوت: عدّل القصيدة، فعّل خيار حذف الملف الحالي عند الحفظ، ثم اضغط حفظ.
