القافية | تحديث قسم المقالات التحريري (20 أكتوبر 2026)
=================================================

التحديث مبني على ملف المستخدم الأخير AlQafiyah(3).zip.

التعديلات الجديدة محصورة في قسم المقالات ولوحة تحرير المقال، ولا تمسّ سجال أو مجيب
أو صفحات الشعراء والقصائد والكتب أو إعدادات الموقع العامة.

كيف تحدّث الموقع:
1. احتفظ بنسخة احتياطية من ملفات الموقع وقاعدة البيانات (قبل النشر).
2. فك ضغط ملف FIX-ONLY وانسخ الملفات إلى نفس مستوى admin.html وindex.html
   في مجلد موقعك، مع استبدال الملفات الموجودة فقط. لا تحذف أي ملف قديم.
3. إذا رغبت في استخدام ملف FULL بدلاً منه، ادمج محتوياته مع مشروعك الحالي
   ولا تحذف مجلد .git الموجود عندك.
4. نفّذ في مجلد الموقع:
   git add . && git commit -m "Update Qafiyah articles" && git push origin main
5. انتظر اكتمال النشر من Cloudflare إذا كان مربوطاً بـ GitHub.

لا يلزم SQL جديد: المحرر يحفظ عناصر المقال في حقل content النصي الموجود حالياً
بتنسيق منظّم متوافق مع المقالات القديمة؛ تبقى المقالات القديمة مقروءة كما كانت.

استخدام لوحة الإدارة > المقالات > إضافة مقال:
- حدد العنوان، الكاتب، التصنيف، ونبذة مختصرة اختيارية.
- «صورة بطاقة المقال» مستقلة عن محتوى المقال؛ تظهر مربعة بنسبة 1:1 في القائمة.
- أضف فقرات وعناوين وصوراً ومقاطع فيديو واقتباسات بالترتيب الذي تريده.
- استخدم سهمي أعلى/أسفل لتحريك العناصر، واختر مربع 1:1 أو 4:3 أو 16:9
  أو عرضاً كاملاً لكل صورة أو مقطع على حدة.
- اضغط حفظ لرفع الملفات وحفظ محتوى المقال.
- عند فتح مقال قديم نصي، يتحول إلى فقرات قابلة للتعديل دون فقد النص.
- كتابة اسم الكاتب تجعل الاسم رابطاً إلى صفحة عامة تعرض مقالات الكاتب نفسه.

القراءة:
- أحدث مقال في الأعلى أكبر من بقية المقالات.
- الجوال: مقال واحد في كل صف. الحاسوب: أحدث مقال عريض ثم عمودان.
- صفحة التفاصيل: عنوان وتصنيف بلون مستقل ورابط الكاتب ونبذة اختيارية.
- أدوات تغيير الخط (+ / -) والمشاركة تعتمد على أدوات القراءة الموجودة أصلاً.
- صور ومقاطع داخل المقال لا تعتمد على صورة البطاقة ولا تُضاف تلقائياً.

مهم حول استضافة الملفات:
- تستخدم ملفات الصور والفيديو المرفوعة مخزن Supabase الحالي (qafiyah-media).
- يتطلب رفع الملفات أن يعمل رفع الصور في لوحة الإدارة أصلاً وأن تكون صلاحيات
  storage المطبقة على مشروعك تسمح للمستخدم المصرح له بالرفع.
- روابط الوسائط المضمنة ينبغي أن تكون عامة وقابلة للعرض للزوار.
- لا تُرفع الصورة إلا بعد الضغط على حفظ المقال.

ملاحظات التحقق:
- فُحصت صياغة الملفات البرمجية، وتوليد بطاقات المقالات على الجوال والحاسوب،
  وعدم تجاوز عرض الشاشة، وتوليد العناصر النصية والوسائط، وسلوك محرر العناصر.
- لم تُجرَ تجربة رفع/حفظ حقيقية على قاعدة بياناتك المنشورة؛ اختبر بمقال تجريبي
  واحد على بيئة اختبار قبل النشر العام. لم نغير أي SQL أو سياسات وصول.
